# 用户列表识别与激活

## 用户键

`UserList` 不再维护 `name → User` 映射，行身份完全由右键菜单「复制 QQ 号」得到的号码
决定：`/v1/contacts:query` 返回的 `contacts` 以精确 QQ 号为 key，聊天记录、发送、读取
都使用同一个号码作为稳定身份。昵称 OCR 方案已整体移除（`utils/vision/compose.py`
拼图 OCR 一并删除）。

## 列表刷新

`UserList.refresh_image()`：

1. 确保 QQ 主窗口就绪并取整窗截图（WGC，会等待当前已渲染帧）。
2. 用模板定位搜索栏，得到好友列表区域。
3. 用霍夫圆检测头像圆，按 `cy` 排序；每个头像即一个用户行，裁出该行区域。

行身份不来自 OCR。需要号码时逐行右键 → 在点击点附近的小 ROI 内匹配
`templates/copy_qq_number.png` → 点击 → 校验剪贴板序列、进程归属与纯号码
（见 `utils/qq/contact_number.py`）。

## 按 QQ 号查找与激活

`UserList.active_user_by_number(qq_number)`：

1. `ContactScanner.scan(qq_number)` 逐屏滚动，每屏对每行复制一次号码，精确匹配目标号。
2. 扫描页已经标出当时的激活行；若目标行就是激活行则跳过点击——真机实测点击已激活行
   会把激活高亮切掉（226 灰 → 245 灰），反而让随后的确认读不到激活行。
3. 否则点击目标行头像圆心激活会话。
4. 点击后 QQ 需要约 0.25s 重绘，因此在 4 秒确认窗口内重试：复制当前激活行号码，
   与目标号完全相等才算成功。

失败语义：号码格式非法 `QQ_CONTACT_NUMBER_INVALID`；确认阶段读不到号码
`QQ_CONTACT_NUMBER_COPY_UNAVAILABLE`；确认到的号码与目标不符
`QQ_CONTACT_NUMBER_ROW_CHANGED`。

## 激活判定

是否已激活以行背景色带（绝对色）为准，不再读取右上角标题 OCR：

- 浅色主题：激活行约 226 灰，未激活约 245 灰，被鼠标悬停的未激活行约 235 灰。
- 深色主题各降一档。
- 色带内唯一命中即采纳；多行命中报 `QQ_CONTACT_NUMBER_ACTIVE_AMBIGUOUS`；
  无命中报 `QQ_CONTACT_NUMBER_ACTIVE_NOT_FOUND`（当前无可见激活会话）。

真机实测悬停在激活行上不改变它的底色，因此色带判定与指针位置无关。不使用「相对离群」
兜底：常驻 235 灰的未读行会被误算成候选，在激活行滚出可视区时报出假歧义。

## 滚动查找

`POST /v1/contacts:query` 支持无请求体或 `{}`（只读当前屏），也可传
`{"qqNumber":"2881734702"}`：服务先刷新当前一屏，仅在未找到目标时才滚动。

扫描只在已识别的联系人区域内滚动，不点击、不切换会话：

- 先以一档滚轮逐段向上确认顶部，再向下逐屏精确匹配；不能假设一次大幅滚轮已回到顶部。
- 用同屏头像像素指纹的实际位移判断滚动量与是否到达末尾，最多 20 屏 / 90 秒。
- 找到目标立即停止，列表保持在目标所在位置；不会把跨屏旧坐标合并成可点击列表。
- 未找到报告 `QQ_CONTACT_NOT_FOUND`；达到边界报告 `QQ_CONTACT_SCAN_LIMIT`；
  窗口/区域变化报告 `QQ_CONTACT_SCAN_CHANGED`。
- 行是群或菜单没有「复制 QQ 号」时返回跳过（`SKIPPED_COPY_UNAVAILABLE`），
  不回退昵称 OCR、不猜坐标。

## 区域定位缓存

区域坐标可以缓存，但只缓存「已经划分的区域位置」和模板定位信息，不缓存截图内容。
`utils/qq/region_cache.py` 根据模板版本/存储实例、QQ 进程、窗口句柄、DPI、窗口矩形、
最大化状态和截图尺寸生成签名：

- 窗口签名不变时持续复用用户列表区、输入框区、消息区坐标，默认不按时间失效。
- 每次仍使用当前 WGC 截图重新裁剪区域；只对固定锚点保存小区域像素摘要，锚点外观
  改变时失效，不保存旧截图。
- 窗口移动、缩放、进程/句柄、DPI/像素尺寸或模板版本变化时重新执行模板定位。
- `QQ_REGION_CACHE_TTL` 默认 `0`；显式设为正秒数时仍可强制定期重新定位。
- 右键菜单的「复制 QQ 号」和消息多选工具栏是动态位置，每次都在当前截图中匹配，
  不复用固定区域坐标缓存。

## 点击坐标

点击使用整窗截图中的头像圆坐标，点击前加上截图时窗口的屏幕原点：

```text
click_x = screen_region.left + circle_x
click_y = screen_region.top  + circle_y
```

头像圆按当前列表区域的 `left/right/top` 动态过滤，不使用固定像素阈值。点击在
`WindowCaptureCtx` 中执行，临时置顶但不抢焦点。
